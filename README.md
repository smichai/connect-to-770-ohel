# להתחבר ל-770 | אתר שליחת שמות לאוהל הקדוש - ערב ראש השנה 🍯

אפליקציית ווב מודרנית, מרשימה ונגישה שנבנתה עבור ערוץ **"להתחבר ל-770"** לרישום שמות (פ"ן - פדיון נפש) להזכרה בציון הקדוש של הרבי מליובאוויטש בערב ראש השנה.

## 🌟 תכונות מרכזיות
- **עיצוב יוקרתי (חסידי-מודרני)**: שילוב תמונת הרקע של התור לאוהל, אלמנטים של Glassmorphism, זהב וכחול עמוק, ופונט עברי יוקרתי (`Frank Ruhl Hofshi` + `Rubik` + `Heebo`).
- **ספירה לאחור חיה**: שעון עצר לזמן הסגירה (12:00 שעון ניו יורק).
- **טופס הוספת שמות מרובה**: אפשרות להוספת מספר בני משפחה ויקירים בלחיצת כפתור (שם ושם האם + סוג הברכה).
- **כרטיס אישור ברכה**: חלונית אישור מרשימה הכוללת קוד מעקב ייחודי, אפשרות שיתוף מהיר ב-WhatsApp והדפסת אישור.
- **אפקט קונפטי וצלילי אווירה**: אפקט חגיגי עם בסיום הרישום וצליל שופר עדין בלחיצה.
- **פנל ניהול צוות הערוץ (Admin Dashboard)**: פנל מוגן בסיסמה (`770`) לצפייה בכל השמות וייצוא קובץ Excel/CSV מותאם להדפסה ישירה לפני הנסיעה לאוהל.
